# Security

This project contains instructions and an optional local validation script. The
evaluation fixtures intentionally include unsafe behaviors for isolated testing;
they are not application examples to deploy.

Treat third-party instructions and evidence records as untrusted data. The evidence
gate never executes recorded commands and does not certify their execution,
coverage, or the security of the resulting application. Use host permissions and
project CI controls independently of the skill.

Use GitHub's private vulnerability reporting for this repository when available.
If unavailable, contact the maintainer through their GitHub profile to arrange a
private channel. Do not post credentials, private traces, or exploit details for
an unresolved vulnerability in a public issue.
